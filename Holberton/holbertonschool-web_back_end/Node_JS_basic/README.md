# Node.js – Bases

Projet d’introduction à Node.js côté back‑end.

## Contenu

- 0-console.js – affiche des messages sur la sortie standard.
- 1-stdin.js – lit l’entrée standard et interagit avec l’utilisateur.
- 2-read_file.js – lit un fichier de manière synchrone.
- 3-read_file_async.js – lit un fichier de manière asynchrone.
- 4-http.js – serveur HTTP basique en Node pur.
- 5-http.js – version améliorée du serveur HTTP (logique supplémentaire).
- 6-http_express.js – serveur HTTP utilisant Express.
- 7-http_express.js – version étendue du serveur Express.

Les fichiers `*-main.js` sont fournis pour tester chaque script.
