# ES6 – Classes

Exercices pour apprendre à définir et utiliser des classes en JavaScript moderne (ES6).

## Contenu

- 0-classroom.js – classe simple représentant une salle de classe.
- 1-make_classrooms.js – crée plusieurs instances de Classroom.
- 2-hbtn_course.js – classe décrivant un cours (nom, longueur, élèves).
- 3-currency.js – classe pour gérer des devises.
- 4-pricing.js – classe combinant prix et devise.
- 5-building.js – classe de base abstraite pour des bâtiments.
- 6-sky_high.js – classe dérivée de Building.
- 7-airport.js – classe représentant un aéroport.
- 8-hbtn_class.js – classe avec logique de validation dans les setters.
- 9-hoisting.js – exemple lié au hoisting de classes.
- 10-car.js – classe Car avec méthodes asynchrones/symboliques (selon le sujet).

Chaque fichier `*-main.js` sert de script de test/démonstration.
