# Python – Async comprehension

Exercices sur les compréhensions asynchrones et la collecte de données depuis des générateurs async.

## Contenu

- 0-async_generator.py – générateur asynchrone qui produit des valeurs.
- 1-async_comprehension.py – utilisation de compréhensions asynchrones pour consommer le générateur.
- 2-measure_runtime.py – mesure le temps d’exécution de plusieurs compréhensions async en parallèle.
