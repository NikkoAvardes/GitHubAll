# ES6 – Data manipulation

Exercices pour manipuler des tableaux, ensembles et objets en JavaScript avec les fonctionnalités modernes d’ES6.

## Contenu

- 0-get_list_students.js – retourne une liste d’objets étudiants.
- 1-get_list_student_ids.js – extrait les identifiants des étudiants.
- 2-get_students_by_loc.js – filtre les étudiants par localisation.
- 3-get_ids_sum.js – calcule la somme des identifiants.
- 4-update_grade_by_city.js – met à jour les notes des étudiants par ville.
- 5-typed_arrays.js – exemples de `TypedArray`.
- 6-set.js – opérations simples sur les ensembles (`Set`).
- 7-has_array_values.js – vérifie la présence de valeurs dans un `Set`.
- 8-clean_set.js – nettoie et formate un `Set` en chaîne.
- 9-groceries_list.js – crée une liste de courses avec `Map`.
- 10-update_uniq_items.js – met à jour les éléments uniques dans une `Map`.

Chaque `*-main.js` illustre l’utilisation de la fonction correspondante.
