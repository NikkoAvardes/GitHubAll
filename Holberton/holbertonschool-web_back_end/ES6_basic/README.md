# ES6 – Bases

Petit ensemble d’exercices pour pratiquer les notions de base d’ES6 (ECMAScript 2015).

## Concepts couverts

- Constantes et variables (`const`, `let`, portée de bloc).
- Fonctions fléchées (`() =>`) et contexte de `this`.
- Paramètres par défaut dans les fonctions.
- Opérateurs rest et spread (`...args`).
- Template literals (interpolation de chaînes avec backticks).
- Propriétés abrégées et propriétés calculées dans les objets.
- Méthodes dans les objets littéraux.
- Boucles `for...of` et manipulation de tableaux/objets.

Les fichiers `0-*.js` à `12-*.js` illustrent chacun un concept précis avec un `*-main.js` associé pour tester.
