# Pagination

Petit projet pour implémenter une pagination de données côté back‑end en Python.

## Contenu

- 0-main.py / 0-simple_helper_function.py – fonctions utilitaires simples pour paginer une liste.
- 1-simple_pagination.py – implémente une pagination basique.
- 2-hypermedia_pagination.py – ajoute des métadonnées (hypermedia) à la pagination.
- 3-hypermedia_del_pagination.py – pagination robuste face à des suppressions.
