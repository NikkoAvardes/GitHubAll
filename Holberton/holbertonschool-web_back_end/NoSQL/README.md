# NoSQL – MongoDB

Scripts pour manipuler une base MongoDB depuis la ligne de commande et avec Python.

## Scripts shell

- 0-list_databases – liste les bases MongoDB.
- 1-use_or_create_database – utilise ou crée une base.
- 2-insert – insère un document.
- 3-all – liste tous les documents d’une collection.
- 4-match – recherche des documents par critère.
- 5-count – compte les documents.
- 6-update – met à jour des documents.
- 7-delete – supprime des documents.

## Scripts Python

- 8-all.py – affiche tous les documents d’une collection.
- 9-insert_school.py – insère un document « school » et retourne son id.
- 10-update_topics.py – met à jour les topics d’une école.
- 11-schools_by_topic.py – liste les écoles par topic.
- 12-log_stats.py – affiche des statistiques sur les logs HTTP stockés dans MongoDB.
