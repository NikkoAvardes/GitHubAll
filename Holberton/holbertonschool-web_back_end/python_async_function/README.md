# Python – Async

Exercices pour découvrir les fonctions asynchrones en Python avec `async` / `await` et `asyncio`.

## Contenu

- 0-basic_async_syntax.py – fonction asynchrone simple avec `await asyncio.sleep`.
- 1-concurrent_coroutines.py – exécution concurrente de coroutines.
- 2-measure_runtime.py – mesure du temps d’exécution de fonctions async.
- 3-tasks.py – gestion de tâches asyncio.
