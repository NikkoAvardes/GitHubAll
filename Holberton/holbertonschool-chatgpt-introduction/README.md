# Introduction à ChatGPT – Holberton School

Petit ensemble d'exercices pour découvrir et utiliser ChatGPT sur différents langages et problèmes (Python, HTML, logique de jeu, etc.).

## Arborescence

- debugging/ – scripts et fichiers utilisés pour des exercices de débogage et de raisonnement avec ChatGPT.

## Fichiers (dossier debugging)

- change_background.html – page HTML simple pour manipuler le style (changement de couleur de fond, etc.).
- checkbook.py – script Python simulant un carnet de chèques (suivi de solde / opérations).
- factorial.py – calcul itératif de la factorielle d'un entier.
- factorial_recursive.py – calcul récursif de la factorielle d'un entier.
- mines.py – logique liée à un jeu de type démineur (gestion de grille / bombes).
- print_arguments.py – affiche les arguments passés en ligne de commande.
- tic.py – logique d'un jeu de morpion (tic‑tac‑toe) en Python.

Chaque fichier sert de support pour expérimenter les explications, complétions de code et débogages avec ChatGPT.
