# GitHubAll

Личный архив проектов, учебных работ, прототипов и документов. Репозиторий
объединяет проекты, которые раньше хранились в разных папках на компьютере.

## Содержание репозитория

### `Certificated`

Коллекция профессиональных сертификатов и подтверждений обучения. Здесь
собраны документы по кибербезопасности, облачным технологиям,
контейнеризации и open source.

### `CodePractice`

Папка с небольшими практическими проектами и экспериментами:

- **`VisitkaLinux.html`** — персональная landing page в стиле Linux-терминала
  с интерактивным интерфейсом.
- **`HelloFitnes`** — простой веб-интерфейс для представления программы
  тренировок и упражнений.
- **`WorkoutTracker`** — full-stack версия трекера тренировок:
  React Native/Expo frontend и Python backend.
- **`code.js`** — отдельные эксперименты и практический JavaScript-код.

### `CyberPractice`

Учебный справочник по кибербезопасности. Содержит объяснения базовых понятий,
типов атак, принципов защиты, инструментов, стандартов и рекомендаций по
обучению.

### `Codex`

Архив прототипов, рабочих материалов и экспериментов, созданных во время
разработки. В частности, содержит iOS-прототип **MoneyLocal** — локальный
кошелек на SwiftUI для учета доходов и расходов и импорта резервных копий
Monefy без отправки данных в сеть.

### `Dev PM`

Проекты, связанные с веб-разработкой и задачами для муниципальной полиции:

- **`CarnetDeRonde`** — легкое веб-приложение для записи обходов,
  наблюдений и посещений адресов. Поддерживает сохранение данных в браузере,
  подготовку ежедневного отчета и светлую/темную тему.
- **`arretes-portal`** — MVP-портал для хранения и управления муниципальными
  постановлениями (*arrêtés municipaux*). Планируется фильтрация, просмотр,
  добавление, изменение и удаление документов с авторизацией пользователей.
- **`arrêtés municipaux/arr-t-s-municipaux`** — отдельный прототип/рабочая
  область для проекта портала муниципальных постановлений.

### `FCC-AI`

- **`spendly-expo!` / `spendly`** — мобильное приложение для учета личных
  финансов на Expo. Поддерживает расходы и доходы, категории, историю,
  фильтры по периодам, импорт Monefy CSV, резервное копирование, экспорт,
  темы, валюты и защиту паролем или Face ID.

### `GitHub_Sites`

- **`le-mas-provencal`** — полноценный сайт ресторана/заведения.
  Frontend построен на React и Vite, API — на Hono, база данных подключается
  через Drizzle ORM и Cloudflare D1, а публикация рассчитана на Cloudflare
  Workers.

### `Holberton`

Учебные проекты и задания из курса Holberton School:

- **`Prestau`** — платформа, соединяющая рестораны и временных работников.
  Компании публикуют смены и управляют кандидатами, а работники ищут миссии,
  указывают доступность, откликаются и получают оценки. Проект включает
  NestJS API, React Native/Expo приложение, PostgreSQL, Prisma и JWT.
- **`holbertonschool-Fix_My_Code_Challenge`** — набор заданий по поиску и
  исправлению ошибок в готовом коде на Python, JavaScript, Ruby и C.
- **`holbertonschool-binary_trees`** — реализация операций над бинарными
  деревьями на C: вставка, удаление, обходы, высота, глубина, балансировка и
  проверка свойств дерева.
- **`holbertonschool-chatgpt-introduction`** — учебные задания по применению
  ChatGPT в разработке, анализе кода и решении задач.
- **`holbertonschool-higher_level_programming`** — большая подборка практики
  по Python, JavaScript, SQL и backend-разработке: синтаксис, классы,
  исключения, структуры данных, ORM, сериализация, тестирование и REST API.
- **`holbertonschool-softy-pinko-docker`** — пошаговое изучение Docker на
  full-stack приложении: контейнеризация frontend и Flask backend, Docker
  Compose, Nginx reverse proxy, балансировка нагрузки и масштабирование.
- **`holbertonschool-sorting_algorithms`** — реализация на C пузырьковой,
  вставочной, выборочной и быстрой сортировок с анализом сложности.
- **`holbertonschool-web_back_end`** — задания по backend-разработке:
  современный JavaScript, Node.js, REST, пагинация, NoSQL и асинхронный
  Python.

### `OverviewREADME`

Личные материалы и заготовка персонального сайта/README. Внутри находится
проект `mysite`, предназначенный для презентации профиля и проектов.

### `RNCP5`

Документы для профессиональной сертификации RNCP 5: профессиональное досье,
проектное досье, презентации, резюме технического задания и сопутствующие
материалы.

### `WorkoutTracker`

Мобильный клиент для учета силовых тренировок на Expo и React Native.

Основные функции:

- регистрация и вход;
- каталог упражнений;
- создание тренировочных программ;
- запуск активной тренировки;
- таймер и запись подходов;
- сохранение веса и повторений;
- статистика и история тренировок;
- поиск пользователей и заявки в друзья.

Клиент использует Zustand, Axios и AsyncStorage и подключается к внешнему REST
backend через переменную `EXPO_PUBLIC_BACKEND_URL`. Подробная документация
находится в [README проекта](WorkoutTracker/README.md).

## Важно

В репозитории могут находиться локальные артефакты разработки, например
`node_modules`, виртуальные окружения Python, сборки и временные файлы. Для
публикации репозитория рекомендуется исключить их через `.gitignore`, а также
проверить, что в Git не попали `.env`, пароли, API-ключи и приватные
сертификаты.
