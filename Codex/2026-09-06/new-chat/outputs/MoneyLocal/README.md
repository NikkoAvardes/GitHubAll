# Кошелёк

Локальное приложение для iPhone, написанное на SwiftUI. Данные хранятся только на устройстве.

## Что есть

- Добавление доходов и расходов: сумма, дата, категория и заметка.
- Создание и удаление категорий отдельно для доходов и расходов.
- Импорт резервных копий Monefy, включая операции, категории и счета.
- Защита от повторного импорта одного и того же набора операций.

## Как запустить

1. Откройте `MoneyLocal.xcodeproj` в Xcode 16 или новее.
2. В настройках цели **MoneyLocal** укажите свой идентификатор приложения и команду разработчика Apple.
3. Выберите свой iPhone и нажмите Run.

Для переноса истории откройте в приложении вкладку «Импорт» и выберите файл резервной копии Monefy в приложении «Файлы».

При обработке копии расшифрованная база создаётся во временном каталоге устройства и удаляется сразу после импорта. В сеть данные не отправляются.
